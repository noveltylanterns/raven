```scss

$body-bg: #f8f4ea;
$link-color: #1d5a86;
$btn-font-size: 0.95rem;

// Then import Bootstrap from Composer.
@import "../../../../composer/twbs/bootstrap/scss/bootstrap";
```

Use the import depth that matches your Sass file location.
